# VectoAI

Vecto is a professional-grade bulk vectorization tool tailored for microstock platforms like Shutterstock, Pngtree, and Vecteezy.

## Quick Start (Windows)

- **Start**: Double-click [`run.bat`](run.bat) to start both Backend and Frontend.
- **Stop**: Double-click [`stop.bat`](stop.bat) to stop running server processes.
- **Tunneling**: Double-click [`tunnel.bat`](tunnel.bat) to expose your local frontend to the internet (useful for sharing).

For complete documentation, see [`instruction.md`](instruction.md).
